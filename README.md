# QuickServe 

QuickServe is a simple and user-friendly local service booking web application.

It allows users to discover local service providers, view provider details, book services, and track their booking requests from start to finish.

## ✨ Features

- 🔐 User Sign Up & Login
- 👤 Customer and Provider roles
- 🔎 Search service providers
- 🏷️ Filter services by category
- 🖼️ Provider images and detailed profiles
- 📅 Service booking system
- 📊 Customer dashboard
- 👨‍💼 Provider dashboard
- ⏳ Booking status management
- ✅ Accept / Reject booking requests
- 🔄 Update booking status
- ⭐ Customer reviews and ratings
- 🚪 Logout functionality
- 💾 LocalStorage based data management
- 🎨 Responsive and clean UI
- 🖼️ Hero image slider

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SweetAlert2
